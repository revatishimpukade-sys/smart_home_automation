# smart_home_automation

Repository Description: IoT-based Smart Home Automation system developed during a 1-day hackathon using ESP32, MQTT, and Blynk. Features include automatic room lighting, gas leakage monitoring, mobile app control, emergency alert system, and improved safety, convenience, and energy efficiency.

---

# Project Overview

This project is a Smart Home Automation system designed using ESP32 and IoT technologies.  
The system automates home appliances, improves safety, and enables remote monitoring through the Blynk mobile dashboard.

The project was successfully developed during a 1-day hackathon.

---

# Features

- Automatic room light control using PIR sensor
- Mobile app control using Blynk dashboard
- MQTT-based real-time communication
- Gas leakage detection using MQ2 sensor
- Emergency alert system
- Energy-efficient automation
- Smart monitoring and remote access

---

# Technologies Used

- ESP32
- MQTT Protocol
- Blynk IoT Platform
- PIR Sensor
- MQ2 Gas Sensor
- Arduino IDE

# Workflow

1. Sensors detect environmental conditions.
2. ESP32 processes the sensor data.
3. MQTT protocol transfers real-time information.
4. Blynk dashboard displays device status.
5. Users can monitor and control appliances remotely.
6. Emergency alerts activate during unsafe conditions.
